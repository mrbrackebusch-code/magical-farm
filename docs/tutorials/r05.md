```ghost
farm.onPlant(function (job) {
    for (let index = 0; index < farm.plantCount(job); index++) {
        farm.plantNext(job)
    }
})

farm.onWater(function (job) {
    for (let index = 0; index < farm.waterCount(job); index++) {
        farm.waterNext(job)
    }
})

farm.onTrellis(function (job) {
    for (let index = 0; index < farm.postCount(job); index++) {
        farm.placePost(job)
        farm.hammerPost(job)
    }
    farm.openGate(job)
})

defenders.onSixShooter(function (job) {
    for (let index = 0; index < defenders.chambers(job); index++) {
        defenders.fireChamber(job)
    }
})

farm.onBaskets(function (job) {
    for (let index = 0; index < farm.basketCount(job); index++) {
        farm.pickClump(job)
        farm.carryBasket(job)
        farm.depositBasket(job)
    }
})

defenders.onTwinbud(function (job) {
    for (let index = 0; index < defenders.twinCycles(job); index++) {
        defenders.fireLeft(job)
        defenders.fireRight(job)
    }
})

farm.onBlooms(function (job) {
    let power = 1
    for (let index = 0; index < farm.bloomCount(job); index++) {
        farm.growBloom(job, power)
        power += 1
    }
})

defenders.onMineberry(function (job) {
    for (let index = 0; index < defenders.trapCount(job); index++) {
        defenders.nextTrap(job)
        defenders.dropMine(job)
    }
})
```

## Bloom Forge: make each repetition different

Five bloom sites need increasing power: 1, then 2, then 3, then 4, then 5. A repeat alone would do the same thing each time, so you need a value that changes as the loop runs.

## Grow power from 1 upward

In ``||variables(noclick):Variables||``, choose **Make a Variable** and name it ``||variables(noclick):power||``. Find ``||variables(noclick):set power to||``, the small ``||variables(noclick):power||`` value block, and ``||variables(noclick):change power by||`` there. In ``||farm(noclick):Farm jobs||``, find ``||farm(noclick):on bloom work requested||``, ``||farm(noclick):bloom sites for job job||``, and ``||farm(noclick):grow next bloom with power power for job job||``.

Set `power` to `1` before the repeat. Let **bloom sites for job job** control the repeat count.

Inside the loop, give the current `power` to **grow next bloom with power power for job job**. Then change `power` by `1` so the next repetition uses a larger value.

The order matters: use the current power first, then increase it. Run the Bloom Forge. The five baseline blooms should show 1, 2, 3, 4, 5.

## Mineberry: use an ordered repeat

At Defense Prep, find ``||defenders(noclick):on Mineberry power requested||``, ``||defenders(noclick):prepared trap patches for job job||``, ``||defenders(noclick):move to next trap patch for job job||``, and ``||defenders(noclick):drop mineberry for job job||`` in ``||defenders(noclick):Defender powers||``.

One trap cycle has two steps in order: move to the next trap patch, then drop the Mineberry there. Use **prepared trap patches for job job** as the repeat count.

Run the preview. At baseline, five prepared patches should each hold a Mineberry.
