## Fence & Trellis: repeat a whole work unit

Each support needs two actions in order: place the post, then hammer that post. The vine gate is different: it should open once after all of the repeated support work.

## Build one complete support again and again

Find ``||farm(noclick):on trellis work requested||``, ``||farm(noclick):trellis posts needed for job job||``, ``||farm(noclick):place next trellis post for job job||``, ``||farm(noclick):hammer current post for job job||``, and ``||farm(noclick):open vine gate for job job||`` in ``||farm(noclick):Farm jobs||``. You already know ``||loops(noclick):repeat||`` from A1.

One support is a two-block work unit: **place next trellis post**, then **hammer current post**. Put that whole work unit inside one repeat, and let **trellis posts needed for job job** control the count.

After the repeat finishes, add **open vine gate for job job** once underneath the loop. If the gate block sits inside the repeat, your code is asking it to open before the support job is finished.

Run the trellis interaction. Every visible support should finish in order, and then the vine gate should open once.
