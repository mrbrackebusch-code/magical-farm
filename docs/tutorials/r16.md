## Stormbloom Projection: final synthesis

The temporary projection lets you program Stormbloom before the final raid without giving you the real crop early. Baseline anatomy is 3 bulbs with 3 sparks in each bulb.

## Keep both loop dimensions and decide for every spark

Before building, predict the baseline total: 3 bulbs × 3 sparks means 9 target decisions. The important part is still the grouping: three spark decisions belong to each active bulb.

In ``||defenders(noclick):Defender powers||``, find ``||defenders(noclick):on Stormbloom power requested||``, ``||defenders(noclick):spark bulbs for job job||``, ``||defenders(noclick):sparks in each bulb for job job||``, ``||defenders(noclick):awaken next bulb for job job||``, ``||defenders(noclick):focus next target for job job||``, ``||defenders(noclick):current target conductive for job job||``, ``||defenders(noclick):zap current target for job job||``, and ``||defenders(noclick):gust current target for job job||``.

Use the outer loop for bulbs. Awaken one bulb once. Inside it, use the inner loop for that bulb's sparks. For every spark, focus a target **before** testing conductivity.

If the current target is conductive, zap it. Otherwise gust it. Keep bulb count and sparks-per-bulb as two separate named reporters rather than flattening them to one total.

The optional postgame upgrades are independent: bulbs can become 4 and sparks-per-bulb can become 4. The same nested algorithm must remain valid for either change.
