## Six-Shooter: use your repeat pattern

The Six-Shooter has a visible chamber capacity. One chamber fires on each repetition. The complete example below uses the familiar repeat pattern.

## Fire every chamber

In ``||defenders(noclick):Defender powers||``, find ``||defenders(noclick):on Six-Shooter Pea power requested||``, ``||defenders(noclick):chamber capacity for job job||``, and ``||defenders(noclick):fire next chamber for job job||``. You can still find ``||loops(noclick):repeat||`` in ``||loops(noclick):Loops||``.

Use the chamber-capacity reporter to decide how many times your repeat runs. Fire one chamber in the loop body.

Like the Farm event, this Defender event supplies a `job` reporter. Connect it to the chamber-capacity reporter and fire action; it identifies this request, so leave it unchanged.

Do not type `6` into the repeat. Six is only the starting chamber capacity; the same code should still work if the plant is upgraded later.

Run the power preview. At baseline, you should see six chamber shots in sequence.
