## Dry Terrace: let the remaining water decide when to stop

The Dry Terrace does not always start with the same amount of water. The same code must handle 3 units, then an empty supply, then 4 units after refill.

## Change the state that controls the while loop

In ``||farm(noclick):Farm jobs||``, find ``||farm(noclick):on irrigation requested||``, ``||farm(noclick):water available at start for job job||``, and ``||farm(noclick):water next dry plot for job job||``. Make a variable named `water` in ``||variables(noclick):Variables||`` and find ``||loops(noclick):while||`` in ``||loops(noclick):Loops||``.

Set `water` once to **water available at start for job job**. That reporter is the starting snapshot; `water` is the learner-owned value your loop will change.

Use `while water > 0`. Inside the loop, water the next dry plot, then change `water` by `-1`. Do not reread the starting-supply reporter as though it were the changing loop variable.

Run the full teaching sequence without editing your code between runs: 3 units should water three plots; 0 units should run the body zero times; after the spring refills to 4, the same code should water four more plots.

If the loop keeps trying after the physical water is gone, inspect whether your learner variable actually decreases. The world will show dry attempts or safety handling rather than secretly repairing the code.
