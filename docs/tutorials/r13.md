## Wash House: combine structures you already know

A10 no longer introduces a new control-flow block. The challenge is to combine familiar structures so the dirty-pod queue resolves correctly.

## Keep washing while dirty pods remain

In ``||farm(noclick):Farm jobs||``, find ``||farm(noclick):on wash work requested||``, ``||farm(noclick):dirty pods remain for job job||``, ``||farm(noclick):load next dirty pod for job job||``, ``||farm(noclick):current pod muddy for job job||``, and ``||farm(noclick):wash current pod for job job||``.

Build a `while` loop that continues while dirty pods remain. Inside the loop, **load the next dirty pod before testing its state**.

Then use `if/else`: if the current pod is muddy, wash it twice with two explicit wash blocks; otherwise wash it once.

Run the Wash House. A muddy pod washed only once should remain visibly unresolved and return to the dirty queue. The world does not add the missing wash for you.

## Retrieve nesting for Sporecap Colony

At Defense Prep, Sporecap uses the same grouped structure as the Greenhouse Grid. In ``||defenders(noclick):Defender powers||``, find ``||defenders(noclick):on Sporecap Colony power requested||``, ``||defenders(noclick):spore caps for job job||``, ``||defenders(noclick):spores in each cap for job job||``, ``||defenders(noclick):open next cap for job job||``, and ``||defenders(noclick):release next spore for job job||``.

The outer loop handles caps. Open one cap once, then the inner loop releases every spore in that active cap.

Baseline is 3 caps × 4 spores. The two optional upgrades are independent: cap count can become 4 while spores-per-cap stays 4, or spores-per-cap can become 5 while cap count stays 3. Keep both named reporters in the nested structure so the same code handles either change.
