## Berry Patch: repeat a work cycle

Four starter transfers are waiting. Each one must be picked, carried, and deposited in that order.

## Move every starter basket

Find ``||farm(noclick):on basket work requested||``, ``||farm(noclick):starter baskets for job job||``, ``||farm(noclick):pick next starter clump for job job||``, ``||farm(noclick):carry current basket for job job||``, and ``||farm(noclick):deposit current basket for job job||`` in ``||farm(noclick):Farm jobs||``.

One complete basket cycle is **pick next starter clump → carry current basket → deposit current basket**. Build that three-action cycle inside a repeat and let **starter baskets for job job** decide how many cycles run.

Run the basket interaction. At baseline, all four transfers should finish. If the actions are in the wrong order, the world will not silently rearrange them for you.

## Twinbud: retrieve the same pattern

At Defense Prep, find ``||defenders(noclick):on Twinbud power requested||``, ``||defenders(noclick):paired firing cycles for job job||``, ``||defenders(noclick):fire left head for job job||``, and ``||defenders(noclick):fire right head for job job||`` in ``||defenders(noclick):Defender powers||``.

You have already built ordered actions inside a repeat. Here, one complete firing cycle is **left head, then right head**. Use **paired firing cycles for job job** as the count.

Run the preview. Baseline Twinbud should fire four complete left/right pairs. There is no finished answer picture on this page unless you open the final hint.
