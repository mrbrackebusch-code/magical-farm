## Starter Beds: first repeats

Six empty plots are waiting in the Starter Beds. One plot takes one planting action, so this is the first place to make one piece of code do repeated work.

You will program planting first, then reuse the same loop idea for watering.

## Plant every unlocked plot

Find ``||farm(noclick):on planting requested||``, ``||farm(noclick):unlocked planting plots for job job||``, and ``||farm(noclick):plant next plot for job job||`` in ``||farm(noclick):Farm jobs||``. Find ``||loops(noclick):repeat||`` in ``||loops(noclick):Loops||``.

The planting event gives you a small `job` reporter. Use that same `job` in the planting-count reporter and the planting action. `job` only identifies this farm request; do not change or calculate it.

Make the repeat count come from **unlocked planting plots for job job**. At the start of the game that reporter says 6, so the helper plants six plots without your code containing a fixed `6`.

The loop body is the code that is surrounded by the loop. Put **plant next plot for job job** inside that body.

Run the game and use the Starter Beds' planting interaction. All six baseline plots should fill in sequence.

## Now water the same beds

Now find ``||farm(noclick):on watering requested||``, ``||farm(noclick):unlocked watering plots for job job||``, and ``||farm(noclick):water next dry plot for job job||`` in ``||farm(noclick):Farm jobs||``.

Build the watering job with the same repeat shape you just used for planting. Let **unlocked watering plots for job job** decide how many times the loop runs, and keep the event's `job` connected to the reporter and action.

Run the watering interaction. All six baseline plots should become watered. If a dry plot remains, use the visible result to check your repeat before asking for a hint.
