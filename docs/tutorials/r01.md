## Starter Beds: first repeats

Six empty plots are waiting in the Starter Beds. One plot takes one helper planting action, so this is the first place to make one piece of code do repeated work.

You will program planting first, then reuse the same loop idea for watering.

## Plant every unlocked plot

Find ``||farm(noclick):when planting helpers are called||``, ``||farm(noclick):unlocked planting plots for job job||``, and ``||farm(noclick):have helper plant next plot for job job||`` in ``||farm(noclick):Farm jobs||``. Find ``||loops(noclick):repeat||`` in ``||loops(noclick):Loops||``.

The planting event gives you a small `job` reporter. Use that same `job` in the planting-count reporter and the planting action. `job` only identifies this farm request; do not change or calculate it.

Make the repeat count come from **unlocked planting plots for job job**. At the start of the game that reporter says 6, so the helper plants six plots without your code containing a fixed `6`.

The loop body is the code that is surrounded by the loop. Put **have helper plant next plot for job job** inside that body. Each time the body runs, the helper plants one plot.

Run the game and use the Starter Beds' planting interaction. All six baseline plots should fill in sequence.

## Now water the same beds

Now find ``||farm(noclick):when watering helpers are called||``, ``||farm(noclick):unlocked watering plots for job job||``, and ``||farm(noclick):have helper water next dry plot for job job||`` in ``||farm(noclick):Farm jobs||``.

Build the watering job with the same repeat shape you just used for planting. Let **unlocked watering plots for job job** decide how many times the loop runs, and keep the event's `job` connected to the reporter and action. Each repetition has the helper water one dry plot.

Run the watering interaction. All six baseline plots should become watered. If a dry plot remains, compare your repeat with the complete example.

## Go play A1

When planting and watering both work, leave the Recipe and play the farm. Face the blinking raid pad and press **A**, then choose **BEGIN RAID**. Your living, watered starter plants defend the beds. Press **B** to swing the Garden Blade at monsters in front of you.

Monsters attack the plants. Protect them: losing plants can make the raid fail. When you win, surviving crops become mature immediately, ready to harvest.

The Recipe does not clear the raid or award Six-Shooter. Those happen only through the game.
